# WJ Website Backup

WJ Website Backup is a WordPress plugin by Webjooll for website and database backups.

## Source Code

The human-readable source code for this plugin is maintained in this public repository:

https://github.com/workplace36/wj-website-backup

The repository includes the plugin PHP source and JavaScript assets for review and maintenance.

## JavaScript Assets

- `assets/admin.js`
- `assets/admin-download.js`

These files contain the JavaScript source used by the plugin.
